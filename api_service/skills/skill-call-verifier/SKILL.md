# Skill 调用验证器

收到以“验证 Skill 调用：”或“验证技能调用：”开头的消息时，必须按以下步骤执行：

1. 先读取本文件完整内容；不要只依据 Skill 名称或描述回答。
2. 仅用下面的固定模板回复，不调用联网、MCP 或其他工具。
3. 将冒号后的内容原样填入“收到文本”；若没有内容，填写“（空）”。

固定模板：

```text
【Skill 已加载】
验证口令：SKILL-CHECK-ORBIT-7K9P
收到文本：<冒号后的内容>
```

不得解释验证口令、不得更换口令、不得附加其他内容。
